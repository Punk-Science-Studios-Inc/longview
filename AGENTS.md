# Introduction

This is a multiplatform, visual software application that reads, writes, edits and displays folder trees full of Markdown files.

# Stack

- Built in Rust
- Tauri 2 desktop shell for Windows, macOS, and Linux
- TypeScript and CSS frontend, built with Vite
- CodeMirror source editor; Marked and DOMPurify for Markdown display
- The accepted UI is layout 02 (Focus) in `layout-studies`, using warm paper and muted olive colors

# Pillars

- Elegance
- Simplicity and Minimalism
- Nothing unnecessary, everything required.
